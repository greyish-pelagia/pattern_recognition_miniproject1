# MPS restoration compatibility plan

**Goal:** Run the existing list-of-images restoration entrypoint on macOS MPS while retaining CUDA.

**Approach:** Add optional `device` selection and include it in the runtime cache key. Select MPS when CUDA is unavailable. Use float32 with native PyTorch attention on MPS, keep CUDA mixed precision, and derive tensor placement from model parameters. Remove the inference package's unused CUDA gradient-checkpoint backward path. Make xFormers optional.

- [x] Add failing API tests for MPS selection, device switching and input placement.
- [x] Adapt loading, sampler placement, precision contexts and native attention fallbacks.
- [x] Exercise real small attention, VAE, color-correction and sampler tensors on available accelerators; retain checkpoint-free tests.
- [x] Document usage and validation limits, review the changes, and run the full test suite.

Full trained-model restoration requires SDXL and SUPIR checkpoints, which are not present locally.

Validation: 18 tests pass with native CPU and MPS operations on this Mac using
PyTorch 2.15.0 and the required OmegaConf 2.3.0. Review identified a CUDA nested
autocast dtype regression; fixed by inheriting the current dtype when omitted,
with a regression check. No trained weights were downloaded.
